## 3. 진단 (train_log; 행은 평가보다 208~832 env step 앞)

- **5k 시점 상태** (α / H / |μ| → 성공률): prefill_fixa03 0.300 / 16.3–17.3 / 0.26–0.29 → 0.42/0.37/0.69; prefill_t12i_a015 0.12 / 9.8–12.0 / 0.49–0.54 → 0.10/0.62/0.13; prefill_t12i 0.10 / 8.1–10.3 / 0.56–0.62 → 0.02/0.12/0.15; mix_prefill 0.17 / 17.1–17.9 / 0.15–0.25 → 0.72/0.76/0.86; fixalpha_03 0.300 / 13.4–15.6 / 0.33–0.43 → 0.65/0.49/0.19; tent12i 0.12–0.15 / 10.6–13.4 / 0.44–0.50 → 0.07/0.74/0.78.
- **α 과도**: 초기값(0.15 / 0.30 / 1.0)은 로그에 없다(첫 행 online 1,200: 0.102 / 0.196 / 0.643). a015는 2,400에 최저 0.075, 5k 직전 0.12, 7,200에 0.15 회복. α 손실 기울기 = H − 목표, Adam이 step당 ≈ lr만큼 log α를 움직이므로 H₀ > 12인 한 초기값과 무관하게 먼저 내려가고 초기값은 위상만 옮긴다.
- **"수준 규칙"은 상관이다**: 73 run 5k 점에서 Spearman |μ| −0.58, H +0.55; |μ| ≥ 0.5에서 dip 26/36, < 0.5에서 14/37. 예외 a015 s2(α 0.123, H 9.8 → 0.62), tent12i s2(0.133, 10.6 → 0.74). 상태를 맞추면 데모 유무로 dip 비율이 다르지 않다(4/5 vs 9/10). 5–20k로 넓히면 깨진다(H < 5 상태 41쌍 중 22쌍 ≥ 0.405).
- **Q_W = 엔트로피 보너스**: `qw_mean ≈ 56.8·αH − 48.2`(R² 0.933), `q_start − mc_return ≈ 76.5·αH + 41`(R² 0.945), 계수 ≈ Σ0.99^t = 51.9(Can discount 0.99). 부호 반전은 목표 0 soft-critic arm 전부에 있고, 반전 없이도 dip(hardq, tent12i_hq, rs_025), 반전 있어도 dip 없음(calql_prefill, a015). dip 표지로 쓰지 않는다.
- **배치 구성 교란**: prefill arm의 진단은 데모 상태 배치(offline_p 0.896@5k → 0.624@129k)에서 계산된다. 제어기도 데모 가중 H를 조절해 같은 목표 12에서 데모 arm α 0.14–0.17 vs tent12i 0.20–0.29.
- **prefill_fixa03 s3**의 10–15k 0.28/0.30은 잡음이 아니지만(합산 0.290 ± 0.032) 진단이 s1/s2와 같고 같은 seed는 무데모도 낮다(fixalpha_03 s3 0.19/0.32). seed 고유.

## 6. 발표용 초안 — 30초 답과 주장 등급표 (§21에서 요구, 이 결과까지 반영)

**"critic을 왜 사전학습하나?"** DSRL-NA에서 데모가 온라인 학습기에 닿는 통로는 critic뿐이다(w 라벨 없음, π_dp 고정 → π_W 지도학습 불가). 거의 공짜(시뮬레이터 불필요, seed 공유)이고 O2O 문헌의 표준 처방(Cal-QL)이다. 재보니 dip을 얕게 하고(IQL 0.24 → 0.34, warmupc 회복 84k → 42k) 최종은 못 바꾸며, 값의 눈금은 soft target의 엔트로피 보너스가 25k 안에 지운다(Q_W ≈ 52·αH + 수익 수준). 방아쇠는 온도다: dip은 α/엔트로피가 내려가는 구간과 겹치고, 엔트로피를 붙들면(고정 0.3, 목표 12) 평균 dip이 얕아지지만 후반을 잃는다 — 데모를 넣어도 이 상충은 남는다.

| 주장 | 등급 | 근거 |
