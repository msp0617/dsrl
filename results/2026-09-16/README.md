## 4. 판정과 해석(사전 등록 §24·§23 문자 그대로)

1. **갈래 A 기각**: rs02는 42k 0.370(< 0.404), 127k 0.358(< 0.472), 예측 "α < 1" 실패(α 17–20). fixa015_rs02는 127k 0.085. 대조군 대비 0/3. "Q 스케일 문제였다"는 닫혔다(§24 표 4행).
2. **갈래 B**: cap03은 글자대로 표 3행(42k 0.333 < 0.404)이지만, 같은 행의 "초기 AUC 3/3 음수" 절은 반대로 통과(tent12 대비 +0.062 ± 0.032, 3/3; hq 대비 +0.112 ± 0.011) — 관건 지표(hq형 초반 비용 회피)는 **통과**. 후반은 hq와 같고(127k +0.032 ± 0.057) tent12보다 낫다(+0.125 ± 0.038, 3/3). 그러나 **대조군 tent12i(cap 없음)가 127k 0.485**라 tent12 대비 이득의 약 70%는 α 초기값 효과이고, cap 고유 효과는 대조군 대비 102k +0.117 ± 0.039(3/3), late +0.077 ± 0.030(3/3), 127k +0.037 ± 0.072(1/3) → **시사**(n=3, 127k SE 0.068). cap1은 해롭다(127k 0.240; 대조군 대비 −0.245 ± 0.041, 0/3) → "상한 값은 무관"이 아니라 **용량 비단조**이며 왜 1.0이 ∞보다 나쁜지는 열림.
3. **42k dip은 미해결**: tent12i 계열 전부 0.33–0.39(< π_dp 0.494, ≈ tent12 0.404); cap03의 최저(0.333)가 곧 42k 점이다. cap이 물리는 시점(online ~10–11k)이 42k 평가와 겹쳐 cap이 42k에 작용했을 여지는 거의 없다.
4. **α 초기값 교란(가장 큰 새 사실)**: tent12i − tent12 late +0.098 ± 0.009(3/3), 127k +0.088 ± 0.035(3/3)인데 후반 진단(α 18–20, Q_W 29.5k, H 12, |μ| 0.35–0.37)은 두 arm이 같다. §19.8·9/8 README §6의 "Square에서 목표 12는 후반에 무너진다(0.369 < baseline 0.407)"는 **α₀ = 1.0에서의 관찰**이었고 α₀ = 0.3에서는 재현되지 않는다(0.485 > baseline). hq의 후반 이득(+0.093)과 α₀ 효과(+0.088)는 크기가 같고 tent12i ≈ hq @127k(−0.005 ± 0.015)다 — 단 **가산성은 말할 수 없다**(hq는 α₀ 1.0, tent12i는 α₀ 0.3; 같은 α₀에서 hq 유무를 비교한 것이 아니므로 `square_tent12i_hq` 없이는 "더해지지 않는다"를 쓸 수 없다, 9/16 교정). 공통 요인 후보는 "초반 수천 step의 큰 보너스(α₀ 1.0 × H 15 ≈ 15/step; tent12 bin 0 Q_W 143 vs tent12i 4)"이지만 rs02(초반 α 0.12, Q_W 53)가 후반에 무너지므로 단독 설명은 아니다. 두 arm은 배치(9/6 vs 9/15)와 seed별 평가 세트가 다르다(step-0 상이).
5. **Can 회귀**: cap 0.3은 Can을 해치지 않는다(사전 기준 통과: 5k 0.410 ≥ 0.405 — 단 seed 2/3가 0.405 아래(0.35/0.36), 초기 AUC +0.048 ± 0.055, 129k +0.075 ± 0.045, 3/3 방향 없음). cap이 34–81% 행에서 물렸는데도 129k 0.772는 무데모 Can 최고(fixalpha_03 n=5 0.739 대비 seed-matched +0.047 ± 0.020, 3/3; 초기 AUC는 −0.037 ± 0.015, 0/3). hq(tent12i_hq)와는 전 지표 3/3 차이 → 보너스 70%를 남기는 것과 0으로 만드는 것은 다르다.
6. **`can_prefill_fixa015`(§23 판별)**: (1) 5,008 seed 평균 0.473 ≥ 0.405, 5k bin 상태 α 0.150 / H 11.5 / |μ| 0.50(조건 밴드 안) → **5k dip은 α≈0.15 "수준"이 아니라 auto-α "과도"에 묶인다**(prefill_t12i 0.097·a015 0.283과 같은 α·H 수준에서 +0.377 ± 0.129, +0.190 ± 0.031, 모두 3/3). 단 seed별 0.31/0.75/0.36 — 2/3가 0.405 아래이고 s1은 10k에 0.27 → "seed 평균에서 prefill_t12i형 dip 없음"까지. (2) 104k/129k 평균 0.898 ≥ 0.80 → **데모의 후반 이득은 제어기 없이 나온다**; 고정 0.3의 무익함(§23)은 **α 수준(0.3이 데모 배치에 너무 높음)** 때문이다(prefill_fixa03 대비 late +0.163 ± 0.042, 129k +0.167 ± 0.077, 3/3). 129k 0.930 ± 0.021은 Can 최고 표본평균이나 a015 0.892(+0.038 ± 0.036)·prefill_t12i 0.870(+0.060 ± 0.085)과 SE 안 → "최고"는 시점을 붙여서만. 엔트로피는 9.3–11.6 유지(붕괴 없음), Q_W 35–60.
